# Figures

This directory contains charts, plots, and other visualizations generated during the project.

## Naming Convention

Use descriptive filenames that identify the content of each figure.

Examples:

- `monthly_sales_trend.png`
- `customer_distribution.png`
- `correlation_heatmap.png`

## Guidelines

- Use descriptive filenames instead of generic names such as `figure1.png`.
- Prefer commonly supported formats such as PNG or SVG.
- Ensure that charts have clear titles, labels, and legends when appropriate.
- Avoid committing unnecessary intermediate figures.
- Keep the code used to generate figures in the corresponding notebooks or scripts.
