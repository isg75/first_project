# Notebooks

This directory contains the Jupyter notebooks used for data exploration, cleaning, analysis, and visualization.

## Naming Convention

Use the following naming convention:

`purpose_username.ipynb`

Examples:

- `explore_data_alex.ipynb`
- `clean_data_maria.ipynb`
- `analyze_customers_sam.ipynb`

## Guidelines

- Choose descriptive filenames that clearly indicate the purpose of each notebook.
- Include your username in the filename to identify the author.
- Keep notebooks focused on a specific task or analysis.
- Avoid generic filenames such as `notebook1.ipynb` or `final_version_2.ipynb`.
- Save original datasets in `data/raw/` and processed datasets in `data/clean/`.
- Save figures intended for reports or presentations in `figures/`.
