i# Project Presentation

This directory contains the final presentation of the project's results and conclusions.

You can prepare your presentation using PowerPoint, Google Slides, or another presentation tool.

## Naming Convention

Use descriptive filenames for your presentation files.

Examples:

- `project_presentation.pptx`
- `final_project_presentation.pdf`
- `google_slides_link.txt`

## Using Google Slides

If your team uses Google Slides, create a plain text file named `google_slides_link.txt` in this directory.

The file should contain the URL of your Google Slides presentation.

**Important:**

- Make sure the presentation is accessible to anyone with the link.
- Set the sharing permission to **Viewer** (read-only).
- Verify that the link works without requiring access approval.
- Do not grant editing permissions to the public.

## Guidelines

- Keep the presentation focused on the project's objectives, methodology, findings, and conclusions.
- Use clear and readable visualizations.
- Ensure that the results presented are consistent with the project's analysis.
- Avoid committing unnecessary intermediate versions of the presentation.
- Make sure the final presentation or its Google Slides link is available in this directory.
