# SQL Scripts

This directory contains the SQL scripts used to create, populate, query, and analyze the project's database.

## Naming Convention

Use descriptive filenames that clearly indicate the purpose of each script.

Examples:

- `create_tables.sql`
- `import_data.sql`
- `customer_analysis.sql`
- `sales_summary.sql`

## Guidelines

- Organize SQL scripts according to their purpose.
- Use clear and consistent names for tables and columns.
- Include comments to explain complex queries.
- Avoid storing passwords or other credentials in SQL scripts.
- Make sure your scripts can be executed in the correct order when dependencies exist.
